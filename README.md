# Alchemy MMA website

Static site for Alchemy MMA in American Fork, Utah.

- Page content lives in `src/pages/`. The shared header and footer are in `src/layout.html`.
- `python3 build.py` writes the finished pages to `site/`.
- Styles and scripts are edited directly in `site/styles.css` and `site/main.js`.
- Pushing to `main` rebuilds and publishes the site with GitHub Pages.

`FOR-BRIAN.md` lists the copy and photos still waiting on Brian.
